# Математический лагерь — PWA prealpha-pwa-1

Готовый пакет для бесплатного статического HTTPS-хостинга. APK не нужен.
Игра основана на math-camp-prealpha.html: игровая логика, сохранения и динамический размер Белобрыссио сохранены. Встроенные изображения вынесены в файлы с именами по хешу; их содержимое не изменено. Это уменьшает размер index.html и позволяет не дублировать всю графику при каждой правке кода.

## Важно о бесплатности, публичности и правах

GitHub Pages на GitHub Free доступен для публичных репозиториев. Покупать домен не нужно: используется адрес https://ВАШ_ЛОГИН.github.io/math-camp/ . Ни один внешний хостинг нельзя гарантировать бесплатным и доступным навсегда. Храните ZIP проекта и экспортированные сохранения у себя; это позволит сменить хостинг.

Это не юридическое заключение. Публикуйте только если у вас есть права или подходящие лицензии на весь код, изображения, музыку, звуки и название. Бесплатная семейная игра не освобождается от авторских прав. Проверьте условия генераторов и исходных материалов. Не выбирайте лицензию MIT для чужих изображений. Сам факт публичной загрузки не делает все материалы общественным достоянием.

Код и ресурсы публичного репозитория будут доступны другим людям. Не загружайте туда пароли, токены, экспортированные сохранения, персональные данные ребёнка. Здесь нет отдельной серверной базы сохранений; прогресс хранится на устройстве. До публикации проверьте происхождение встроенных материалов. Сам пакет не подтверждает права на них.

## Публикация без установки программ: четыре загрузки через браузер

1. Создайте бесплатную учётную запись на github.com и подтвердите e-mail.
2. Нажмите + → New repository. Имя: math-camp. Visibility: Public. Включите Add a README file, чтобы сразу появилась ветка main. Создайте репозиторий. Не выбирайте платный тариф и не добавляйте платный домен.
3. Распакуйте ZIP. Откройте папку math-camp-pwa: в ней лежат index.html, sw.js, manifest.webmanifest, pwa.js, pwa.css, precache-list.json, README-RU.md, папки icons, art-1, art-2, art-3 и скрытый файл .nojekyll.
4. В репозитории нажмите Add file → Upload files. Для первой загрузки перетащите файлы из корня и папку icons, НО пока НЕ папки art-1, art-2, art-3. Напишите Initial PWA shell → Commit changes. index.html должен оказаться в корне репозитория, не в лишней папке math-camp-pwa.
5. Снова Add file → Upload files. Перетащите целиком только папку art-1 → Commit changes. Затем отдельно повторите для art-2 и отдельно для art-3. Названия папок сохраняйте. В каждой папке не больше 80 файлов, чтобы укладываться в браузерные лимиты загрузки.
6. Если .nojekyll скрыт и не загрузился, это не мешает именам данного пакета. При желании создайте в корне пустой .nojekyll через Add file → Create new file.
7. Убедитесь, что в корне есть index.html, sw.js, precache-list.json, manifest.webmanifest, pwa.js, pwa.css и все четыре папки: icons, art-1, art-2, art-3.
8. Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save. Дождитесь успешной публикации (обычно несколько минут; смотрите вкладку Actions).
9. Откройте адрес, показанный в Settings → Pages. Он должен быть HTTPS и заканчиваться /math-camp/ . Custom domain оставьте пустым. Enforce HTTPS включите, если доступен переключатель.

ZIP не загружайте вместо его содержимого: GitHub не распаковывает его в работающий сайт автоматически.

Альтернатива для компьютера: создать новый локальный репозиторий math-camp в GitHub Desktop, скопировать внутрь содержимое пакета, Commit to main → Publish repository (снять Keep this code private). После этого включить Pages, как описано выше. Не используйте LFS для этих ресурсов — размеры файлов здесь намного меньше обычного лимита Git.

## Установка

1. Сначала в старой одиночной HTML-игре откройте настройки → Создать код → Скопировать код; сохраните код в личной заметке. Можно также скачать полный JSON. Не публикуйте его в репозитории.
2. Откройте HTTPS-ссылку игры на телефоне. В настройках игры внизу есть блок «Приложение».
3. Дождитесь статуса «Готово к игре без интернета». Если офлайн-копия ещё загружается — не закрывайте игру. При первом открытии нужно скачать примерно 24 МБ, плюс обычные накладные расходы.
4. Android/Chrome: меню ⋮ → Установить приложение / Добавить на главный экран. Кнопка «Установить игру» в настройках также может вызвать установку, если браузер её предлагает. При открытии ссылки внутри мессенджера сначала выберите открытие в обычном Chrome.
5. iPhone/Safari: Поделиться → На экран «Домой» → включить «Открывать как веб-приложение», если этот переключатель есть → Добавить. Названия пунктов зависят от версии iOS.
6. Запустите именно с нового значка, откройте настройки и импортируйте код прогресса из старого HTML. Если прогресс уже появился автоматически, не импортируйте старый код поверх более нового.
7. После появления «Готово…» включите авиарежим, полностью закройте и откройте приложение. Проверьте игру. Верните интернет.

Если установка не предлагается: проверьте HTTPS, отсутствие ошибок/404, наличие всех папок, открытие в Chrome/Safari вместо браузера мессенджера. Обычный браузерный ярлык не всегда равен установленному веб-приложению. Возможности различаются по ОС и браузеру.

## Обновления: работаем вместе

1. Сообщите ИИ желаемые изменения и явно попросите: «Обнови PWA Математического лагеря, сохрани формат сохранений, прежний адрес и систему офлайн-обновлений. Текущая версия prealpha-pwa-1». Приложите текущий ZIP или ссылку на публичный репозиторий. Не рассчитывайте, что предыдущая версия всегда будет доступна в истории чата.
2. ИИ должен выдать проверенный пакет следующей версии и точный список изменённых файлов. При обновлении меняется VERSION в sw.js. Если изменились ресурсы — корректируется precache-list.json. Имена графики основаны на содержимом: неизменённые файлы не надо загружать заново.
3. В том же репозитории, по тому же пути, через Add file → Upload files замените только перечисленные файлы. При нескольких загрузках сначала добавьте новые изображения и ресурсы; index.html, precache-list.json и sw.js загрузите вместе последней загрузкой. Это уменьшает риск публикации неполной версии. Дождитесь успешного Pages deployment. Проверяйте новую версию до приглашения брата обновляться.
4. Не переименовывайте репозиторий, не меняйте домен и не создавайте новый репозиторий для каждой версии. Не меняйте ключ/формат localStorage без совместимой миграции. Не удаляйте все файлы перед обновлением.
5. У брата при наличии интернета: настройки игры → Проверить обновления. Старая версия продолжает работать, пока новая загружается целиком.
6. Когда появляется «Новая версия загружена», закончить бой/тренировку/обучение. Нажать «Обновить и перезапустить» и подтвердить. Игра сохраняет прогресс и только затем перезапускается. Переустанавливать значок не нужно.
7. Если нет интернета, текущая сохранённая версия остаётся доступной. Обновление придёт после подключения и проверки. Если загрузка новой версии не удалась, старая активная версия не заменяется.
8. Перед крупными изменениями всё равно экспортируйте прогресс. Мы проверили обновление с сохранением имени и золота, но будущая несовместимая правка может потребовать миграции.

Публикация на GitHub не делает обновление немедленным: требуется успешная сборка Pages, доступ телефона к интернету и завершение загрузки новой версии. Нельзя загрузить только изменённый index.html, оставив прежний sw.js: офлайн-приложение может продолжить открывать старую копию.

## Резервные копии и ограничения

- Храните последний проверенный ZIP и предыдущую рабочую версию вне GitHub.
- Храните свежий код/JSON сохранения отдельно на устройстве или в личном облаке.
- Кэш браузер может очистить; удаление приложения/данных, приватный режим и смена браузера/домена могут лишить локального сохранения или офлайн-копии. Офлайн не означает вечное хранение.
- GitHub Pages предназначен для статических сайтов; это не сервер для онлайновых аккаунтов, платежей или постоянной серверной базы. Правила сервиса ограничивают коммерческие сценарии.
- По актуальной документации: сайт до 1 ГБ, мягкий предел трафика 100 ГБ/месяц; условия могут меняться. Для одной семейной игры текущий пакет значительно меньше ограничения размера, но не обещается неограниченный трафик.
- Нет обязательных подписок, APK, платного домена, магазина приложений или системы платных live updates.
